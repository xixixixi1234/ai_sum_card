# Find a Hotel 实验平台 — 数据指标与测量原理（完整版）

版本 v4.9.9.13 · A/B 双站（编号前缀 A- / B-，各自独立数据库，后台需各自设置）
后台导出位置：`/admin` → Participation 标签。所有文件以 `participant_id`（+ `hotel_id`）为键互相关联。

## 〇、导出文件命名与筛选

每个导出的文件名自动带三段后缀：

```
participants_ai_summary_search_2026-11-02_15-30.csv
            └─ AI条件 ─────┘ └─ 下载日期 ┘└时分┘
```

1. **AI 条件**：按该站当时搜索页 AI 开关 → `_ai_summary_search` 或 `_no_ai_summary_search`
2. **时间窗**（可选）：后台 Export window 填了起止日期时加 `_起~止`；筛选依据是**被试首次访问时间**（first_seen），作用于被试数据文件（participants / hotel_events / saves / votes / review_votes / hover_before_click / interactions）
3. **下载时刻**：你点下载那一刻的本机时间 `_YYYY-MM-DD_HH-MM`

## 一、总体机制

- 被试从 Qualtrics 链接进入，链接携带 `?pid=编号`；**链接中的编号为准**（与本机旧记号不同则开新会话）。同一编号刷新不丢进度。
- 前端追踪器把事件按 `被试 × 酒店` 累积，**每 5 秒批量上报**一次；关闭页面/切走标签时用浏览器 sendBeacon 机制补发最后一包（理论上最多丢失末尾 ≤5 秒的计时）。
- 所有计时只在**标签页处于前台**时进行（Page Visibility API）；切走、最小化立即停表。
- 每位被试的酒店顺序、城市顺序用其编号做种子随机打乱：同一人每次一致，不同人不同，消除顺序效应。
- AI 条件（ai_search / ai_product）在被试**首次注册时按当时开关状态冻结**写入，之后改开关不影响已注册者。
- 时间戳均为服务器 UTC（ISO 8601）；interactions.csv 另含客户端本机时间。
- **"点开详情页前"（before_product_page / before_click）口径**：该被试对**该酒店**的首次点击之前累积的量。点开过一次之后，即使返回搜索页，后续对这家酒店的行为都不再计入该口径（但仍计入总量）。

## 二、participants.csv（每位被试一行）

| 列 | 含义 | 测量原理 |
|---|---|---|
| participant_id | 被试编号（A0001 / B0001…） | 服务器顺序发号或 Qualtrics 链接传入 |
| hotels_liked / hotels_disliked | 当前 Like / Dislike 的酒店数 | votes 表当前态计数 |
| likes_on_search_page / likes_on_product_page / dislikes_on_search_page / dislikes_on_product_page | 按发生页面拆分 | 投票时记录来源页 |
| hotels_saved | 当前收藏的酒店数（总） | saves 表当前态 |
| **saves_before_product_page** | 在点开该酒店详情页**之前**就收藏过的酒店数（去重） | save 事件带 after_detail 标记（动作发生时该酒店 clicks 是否 >0），取 after_detail=false 的不同酒店数 |
| **likes_before_product_page / dislikes_before_product_page** | 点开详情页前就 like/dislike 过的酒店数（去重） | 同上，取 result=set 且 after_detail=false |
| hotels_viewed / hotels_clicked | 看到过卡片的酒店数 / 打开过详情的酒店数 | hotel_events 的 seen / clicks |
| avg_seconds_per_hotel | 平均每家酒店停留 | (列表+详情停留总和)/涉及酒店数 |
| total_seconds_on_site / total_ms_on_site | 网站在前台的累计时长 | 1 秒粒度，仅前台；"有效浏览时长" |
| **seconds_on_search_page / seconds_on_product_pages** | 搜索页 / 所有详情页的前台总时长 | 1 秒粒度页面级计时：列表页挂载时计 search，详情页打开时计 product；主页/弹窗两者都不计 |
| **search_page_entries** | 进入搜索页次数 | 每次列表页挂载 +1（从详情返回也算；刷新落主页不重复计） |
| **product_page_opens_total** | 打开详情页总次数（含重复） | Σ 各酒店 clicks |
| **pager_clicks / saves_drawer_opens / gallery_photo_clicks** | 翻页次数 / Saves 抽屉打开次数 / 相册交互次数 | 对应按钮点击计数，随心跳上报 |
| **mouse_travel_px** | 搜索页上鼠标移动总距离（像素） | mousemove 逐段累加（>400px 的跳变视为指针重入、不计）；"扫视强度"代理 |
| **card_hover_switches** | 悬停从一张卡切换到另一张卡的次数 | 悬停进入的卡 ≠ 上一张悬停的卡时 +1；"酒店间比较/犹豫"代理 |
| finished_at | 点击 Finish study 的时刻 | 只记第一次 |
| **exit_flow_started_at / seconds_in_exit_flow** | 退出弹窗首次打开时刻 / 在退出流程中的秒数 | finished_at − exit_flow_started_at；未完成者后者为空 |
| **browser_user_agent / screen_resolution / window_size / device_pixel_ratio / timezone** | 设备信息（desktop-only 核查） | 注册后首次上报，只记第一台设备 |
| seconds_consent_to_finish | 同意知情书 → 点退出的秒数 | 未点退出者为空（识别中途流失） |
| booked_hotel_id / booked_hotel_name | 退出流程选的"最想预订"酒店 | 单选、可为空 |
| bookmarked_site | 是否点过 Bookmark this site | 站内记号 |
| consented | 是否同意知情书 | — |
| ai_summary_in_search_page / _in_product_page | 注册时冻结的实验条件 | 见总体机制 |
| consent_time | 同意时刻 | — |
| **tutorial_completed_at** | 完成全部新手教程的时刻 | 教程最后一步关闭时前端上报，只记第一次 |
| first_seen / last_seen | 首次、最近活动时刻 | 进入=first_seen；任何上报都刷新 last_seen。**进入/退出时间**即 first_seen → finished_at（或 last_seen） |

## 三、hotel_events.csv（每个 被试×接触过的酒店 一行）

### 3.1 基础与总量指标

| 列 | 含义 | 测量原理 |
|---|---|---|
| hotel_rating / hotel_review_count | 酒店星级与评论数（素材属性） | 便于按评分分组分析 |
| **display_rank** | 该酒店在**这位被试**列表中的初始位次（1=第1页第1张） | 导出时用被试编号种子复现其随机排列；位置效应控制变量。Dislike 隐藏会让后面的卡上移，此列为隐藏前的位次（hover_before_click.csv 同有此列） |
| list_views | 卡片被看到的次数 | IntersectionObserver：露出 ≥50% 计 1 次，滚出再滚回再计；单人单酒店封顶 50 |
| clicks | 打开该酒店详情页的**总次数**（含二次、三次进入） | 任何入口（卡片 / Check 按钮 / Saves 抽屉）均计 |
| vote / vote_page | 当前 Like/Dislike 态及发生页面 | votes 当前态 |
| list_dwell_seconds（_ms） | 卡片在列表中**可见**的累计时长 | 每 1 秒检查视口 ≥50%；同屏多卡各自计时（曝光口径） |
| detail_dwell_seconds（_ms） | 详情页打开且前台的累计时长 | 1 秒粒度 |
| total_dwell_seconds（_ms） | 上两者之和 | — |
| saved / saved_on_page | 当前是否收藏及发生处（search_page / product_page / exit_review） | saves 当前态 |
| reviews_dwell_seconds（_ms） | 评论区在屏幕上的累计时长 | 评论区露出 ≥15% 且前台 |
| reviews_scrolled_to / reviews_shown_total | 滑到的最深评论序号 / 页面共放几条 | 相除得"看完比例" |
| card_hover_seconds（_ms） | 鼠标悬停整张卡片的累计时长（**总量**，含点开详情后返回再悬停） | mouseenter→mouseleave 差值累加 |
| ai_summary_visible_seconds / ai_summary_hover_seconds | AI 摘要块可见 / 被悬停的累计时长（总量） | 区块级 IntersectionObserver + hover |
| description_visible_seconds / description_hover_seconds | 官方简介可见 / 悬停（总量） | 同上 |
| rating_visible_seconds / rating_hover_seconds | 评分行可见 / 悬停（总量） | 同上 |
| price_visible_seconds / price_hover_seconds | 价格区可见 / 悬停（总量） | 同上 |
| reviews_hover_seconds | 评论区悬停（总量） | 同上 |
| photo_hover_seconds / hotel_name_hover_seconds / save_button_hover_seconds / dislike_button_hover_seconds / check_button_hover_seconds | 酒店图片、酒店名、Save 按钮、Dislike 按钮、Check 按钮的悬停时长（总量） | 这些元素与整卡同时可见，故只记悬停不记可见 |

### 3.2 时间戳

| 列 | 含义 |
|---|---|
| **first_seen_at** | 首次看到该酒店卡片的时刻 |
| **first_clicked_at** | 首次点开该酒店详情页的时刻 |
| **last_activity_at** | 对该酒店最后一次任何行为的时刻 |

### 3.3 点开详情页前（before_product_page）口径——与总量成对

以下各列只累计**该酒店首次点击之前**发生的量（点开过就封存，不再增长）：

`list_views_before_product_page` · `list_dwell_before_product_page_seconds` · `card_hover_before_product_page_seconds` · `ai_summary_visible_before_product_page_seconds` · `ai_summary_hover_before_product_page_seconds` · `description_visible_before_product_page_seconds` · `description_hover_before_product_page_seconds` · `rating_visible_before_product_page_seconds` · `rating_hover_before_product_page_seconds` · `price_visible_before_product_page_seconds` · `price_hover_before_product_page_seconds` · `photo_hover_before_product_page_seconds` · `hotel_name_hover_before_product_page_seconds` · `save_button_hover_before_product_page_seconds` · `dislike_button_hover_before_product_page_seconds` · `check_button_hover_before_product_page_seconds`

> 从未点开的酒店：before 列 = 总量列。差值（总量 − before）= 首次点开之后（含返回列表）发生的量。

## 五、行为流水（过程数据，每个动作一行）

### saves.csv — 收藏轨迹
| 列 | 含义 |
|---|---|
| hotel_rating | 酒店星级 |
| action | save / unsave |
| page | search_page / product_page / exit_review |
| **had_opened_product_page** | 该动作发生时是否已点开过这家酒店的详情页（no = 点开前的收藏） |
| **nth_search_page_visit / nth_product_page_visit** | 动作发生时，已第几次在列表看到 / 第几次进详情页 |
| **ai_summary_visible_seconds_before_this_action / ai_summary_hover_seconds_before_this_action** | 动作发生那一刻，该酒店 AI 摘要已累计的可见 / 悬停秒数 → 直接回答"先看摘要还是先收藏"（动作顺序分析） |
| still_saved / at | 当前是否仍收藏 / 时间戳 |

### votes.csv — Like/Dislike 轨迹
结构同 saves.csv：`action`（like / dislike）· `result`（set 生效 / cleared 再点取消）· `page` · `had_opened_product_page` · `nth_search_page_visit` · `nth_product_page_visit` · `ai_summary_visible/hover_seconds_before_this_action` · `time`。改选表现为相邻两行（旧 set → 新 set）。

### interactions.csv — 全量时间戳流水（每次点击、每段悬停一行）
| 列 | 含义 |
|---|---|
| event | click（进详情页）/ card_hover / ai_hover / desc_hover / rating_hover / price_hover / reviews_hover / photo_hover / title_hover / save_hover / dislike_hover / check_hover |
| duration_seconds | 该段悬停的时长（click 行为空） |
| started_at_client | 悬停开始 / 点击发生的**被试本机时间** |
| received_at_server | 服务器收到的时间（UTC；批量上报，与发生时刻差 ≤5 秒） |

> 用途：还原任意动作序列（如"悬停摘要 3.2 秒 → 点开详情 → 返回 → 收藏"），与 saves/votes 的时间戳对表即可排出全过程。

### card_events.csv — Cards 模式逐张决策流水（每张卡一行）

仅在后台 Study mode 设为 **Cards**（逐张强制分类范式）时产生。该模式下被试一次看一张酒店卡，必须在 Save / Not sure / Dislike 中三选一，选完自动下一张、不可回看；刷新从中断处继续。

| 列 | 含义 |
|---|---|
| shown_position | 这张卡是该被试看到的第几张（1 起；同一套酒店、顺序按编号随机） |
| choice | save / not_sure / dislike（save 同时写入 saves 表、dislike 同时写入 votes 表，原有导出照常可用） |
| dwell_seconds / dwell_ms | **卡片出现 → 按下按钮**的停留时长（第 1 张卡从导览关闭后起算） |
| chosen_at_client / received_at_server | 被试本机时间 / 服务器 UTC |

> Cards 模式下无详情页：detail/reviews 类指标为空；各区块可见/悬停（AI、简介、评分、价格、图片等）照常记录在 hotel_events.csv，且 clicks 恒为 0，故 before 列 = 总量列。

### review_votes.csv — 对单条评论的 👍Helpful / 👎Not helpful
被试、评论 ID、like/dislike、所属酒店、评论作者/评分/标题、时间；再点取消则记录删除（表为当前态）。

## 六、内容与配置存档（用于与行为数据合并）

- **hotel_content.csv**：数据库当前的酒店文案（含后台修改）、AI 摘要、字符/词数——以 `hotel_id` 与行为数据合并。改完文案先导一份存档再做任何重置。
- **reviews.csv**：当前线上所有评论全文及元数据（作者为确定性假名）。
- **summary_stats.csv**：酒店层面的描述统计。

## 七、退出流程的时间语义

点 Finish study → 弹窗第 1 步勾选想收藏的（写入 saves，page=exit_review）→ 第 2 步从已收藏中选一家"预订"（写入 booked_hotel）→ 确认后记 `finished_at`。退出弹窗内的操作时间戳都在它之前的几十秒内。

## 八、已知边界（建议写入方法局限）

1. "可见/悬停"≠"阅读"，为注意力代理指标（眼动才能测阅读）。
2. 强制关闭浏览器时，末尾 ≤5 秒的计时可能丢失（sendBeacon 已尽量补发）。
3. 列表可见时长为曝光口径：同屏多卡各自计时，不宜将多家酒店的 list_dwell 直接加总当作"总时间"（总时间用 participants.csv 的 total_seconds_on_site）。
4. before 口径以"首次点击该酒店"为分界，按酒店独立：点开 A 酒店后返回，对 B 酒店（未点开）的行为仍计入 B 的 before。
5. started_at_client 来自被试本机时钟，可能与服务器 UTC 有偏差；顺序分析建议在同一来源的时间列内部比较。
6. 同一编号在多设备使用会按同一被试合并；实验流程中编号由 Qualtrics 链接下发，正常情况下一人一号。
7. 评论者姓名为确定性假名（同一原名恒映射同一假名），评论正文未改写，属 pseudonymized 而非完全匿名。
